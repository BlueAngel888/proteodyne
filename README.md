# Proteodyne

Instrument experimental de sunet și relaxare: transformă secvențe de aminoacizi în melodii (WAV 44,1 kHz), cu stive tematice, asistent de stive și ghid explicativ. Funcționează offline ca aplicație instalată pe telefon (PWA).

Nu are efect terapeutic dovedit și nu înlocuiește tratamentul sau sfatul medicului.

Deschide `index.html` prin GitHub Pages și adaugă pagina pe ecranul principal.
